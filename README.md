# DiGiPanion Patches

A DiGiCo session parser you can drop into another app.

Download [digipanion-parser.zip](https://github.com/HoboTraveler/DiGiPanionPatches/releases/latest/download/digipanion-parser.zip). Unzip it and follow the README inside. The zip contains the parser source, a command that prints a session as JSON, and instructions for using either one.

An input channel's `copyAudio` list is the Reaper patch stored in the session.
